# Gallery 4 — Signals and Sparks

**Placard 4.1 — The Aldis lamp**

Before radio reached small stations, keepers spoke to passing ships in Morse code with a hand-held signal lamp. The brass Aldis lamp in this case could flash a message readable at 8 kilometres in clear weather. A trained keeper sent about twelve words a minute.

**Placard 4.2 — The Marconi set of 1927**

The wooden cabinet beside the lamp is a Marconi spark-gap transmitter, installed at Skerrow Point in 1927. It had a range of about 150 kilometres and was used mainly to report the weather to the coastal board at nine o'clock each morning. Its operating licence was held in the principal keeper's name.

**Placard 4.3 — Try the key**

The telegraph key on the table is a working replica. Visitors can tap their own name in Morse code; the lamp above will repeat it back in flashes. Guided Morse workshops for children aged eight and over run on Saturdays.
