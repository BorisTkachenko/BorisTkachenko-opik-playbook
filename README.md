# BorisTkachenko-opik-playbook

Small, runnable LLM apps that show how to trace, evaluate, and debug them with [Opik](https://github.com/comet-ml/opik).

Examples are being added; each lives in its own folder with a README, a `.env.example`, and offline tests.

Copy `.env.example` to `.env` at the repo root and fill in the keys you need — every example reads it from there.
